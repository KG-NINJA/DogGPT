# 🐾 Dog Talker for ChatGPT / 犬用 ChatGPT 連携タッチパネルボード

[English](#english) | [日本語](#japanese)

---

<a name="english"></a>
## English

A touch-friendly, high-contrast web application designed for dogs to communicate their feelings and request talk with ChatGPT directly. Highly optimized for tablets and mobile devices.

### Features
* **Dog-Friendly Visuals:** Uses a blue and yellow color palette, which are colors dogs can easily distinguish.
* **Accumulate Words:** Touch buttons sequentially to create complex sentences (e.g., "Treat ➔ Outside").
* **Voice Synthesis & Visual Feedback:** Supports Web Speech API for immediate vocal feedback, accompanied by responsive, playful particle effects on touch.
* **English & Japanese Modes:** Supports on-the-fly toggle between English and Japanese prompts and voices.
* **Safe ChatGPT Integration:** Generates a direct persona-based prompt ("*I am a dog...*") which is automatically copied to your clipboard. You can click the ChatGPT button to open it in a new window/tab and paste to start talking.

### How to Use
1. Place your tablet/mobile device on the floor or a sturdy stand.
2. Let your dog tap the big icons (or assist them).
3. The selected words will build a prompt and automatically copy to the clipboard.
4. Tap the **ChatGPT** button to open the chat window, paste, and let ChatGPT respond to your dog!

<a name="japanese"></a>
## 日本語

犬が自分の気持ちを選択し、ChatGPTと直接おしゃべりするためのタッチパネル対応ウェブアプリです。タブレットやスマートフォンに最適化されたフルスクリーン設計です。

### 主な機能
* **犬に優しい色彩設計:** 犬が識別しやすいとされる「青」と「黄」を基調とした配色を採用。
* **言葉の蓄積機能:** ボタンを連続してタッチすることで、「おやつ ➔ おそと」のように複数の要求を連結した文章を作成できます。
* **音声＆ビジュアルフィードバック:** Web Speech API による読み上げ機能と、タッチした場所に絵文字が飛び出すパーティクルエフェクトを搭載。
* **日英対応:** 言語切替トグルにより、プロンプト生成と言葉の読み上げ音声を日本語と英語で切り替え可能。
* **安全なChatGPT連携:** 犬が主体となったプロンプト（例: 「*ぼくは犬だよ...*」）を自動でクリップボードにコピーし、別タブで開いたChatGPTの入力欄に貼り付けるだけでチャットが開始できます。

### 使い方
1. タブレットやスマートフォンを床やスタンドに設置します。
2. ワンちゃんに大きなボタンをタッチしてもらいます（飼い主様が手伝ってあげてもOKです）。
3. 選択された言葉がプロンプトとして構築され、自動的にクリップボードにコピーされます。
4. **ChatGPT** ボタンを押して別ウインドウを開き、入力欄に貼り付けて送信してください。ChatGPTがワンちゃんに直接返事をしてくれます！
